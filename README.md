# 서연·서우 보드

아이들 학원 시간표와 숙제·준비물을 한 화면에서 확인하는 휴대폰용 보드입니다.
GitHub Pages로 열리는 정적 페이지이며, 설치형 앱처럼 홈 화면에 추가해 쓸 수 있습니다.

- **오늘**: 오늘 요일을 자동으로 골라 두 아이의 일정을 보여 주고, 지금 하는 수업과 다음 수업을 표시합니다. 주말에는 요일을 직접 눌러 봅니다. 맨 위에는 함박초 그날의 점심 급식표(메뉴·칼로리)가 함께 보입니다.
- **급식**: 함박초등학교 점심 급식표를 이번 주·다음 주(월~금)로 넘겨 봅니다. 메뉴는 알레르기 번호를 빼고 깔끔하게 보여 주고, ‘알레르기 번호’를 누르면 식약처 번호가 함께 보입니다.
- **시간표**: 아이별로 월~금 시간표를 과목 색으로 구분해 보여 줍니다.
- **숙제**: 아이별 체크리스트. 추가·완료 표시·삭제가 됩니다.
- **편집**: 오른쪽 위 `편집`을 누르면 일정을 추가·수정·삭제할 수 있습니다.

고친 내용은 그 휴대폰의 브라우저 저장소(localStorage)에 저장되며 서버로 전송되지 않습니다.
`설정 · 백업`에서 JSON 파일로 백업하거나 되돌릴 수 있습니다.

## 파일

- `index.html` — 화면과 동작 전체
- `meals.json` — 함박초 급식표(이번 달 + 다음 달, 중식). 없거나 비어 있으면 화면이 NEIS에서 직접 받아 옵니다.
- `manifest.json`, `sw.js`, `icon*.png`, `apple-touch-icon.png` — 홈 화면 추가 및 오프라인용
- `tools/make-icons.py` — 아이콘 생성 스크립트
- `tools/fetch-meals.py` — NEIS에서 급식표를 받아 `meals.json`을 새로 만드는 스크립트 (5일 단위 요청, API 키 불필요)

## 급식 자료

식단은 교육부 NEIS 급식 식단 정보 API(`open.neis.go.kr`, 경기도교육청 `J10` / 함박초등학교 `7751355`)에서 받습니다.
화면을 열 때 이번 주(월~금) 식단을 한 번 더 받아 보고, 실패하면 `meals.json`과 휴대폰에 저장해 둔 마지막 자료로 보여 줍니다.
`python3 tools/fetch-meals.py`를 다시 돌리면 이번 달·다음 달 식단을 새로 채웁니다.
