# 서연·서우 홈 보드

아이들 공부 목록·시간표·급식·숙제를 한 화면에서 확인하는 태블릿/휴대폰용 보드입니다.
GitHub Pages로 열리는 정적 페이지이며, 설치형 앱처럼 홈 화면에 추가해 쓸 수 있습니다.

- **홈 보드** (첫 화면): 태블릿 가로 화면에 맞춘 대시보드입니다.
  - 실시간 시계와 용인 날씨(기온·최고/최저·강수·미세먼지·옷차림) — Open-Meteo, API 키 없음
  - 서연(초5)·서우(초2) 공부 목록 카드: 오늘 요일 자동 선택, 월~일 미리 보기, 항목을 누르면 완료 체크, 완료만큼 ★ 보상이 쌓입니다(날짜별 저장).
  - 수학 퀴즈: 서연은 초5 수준(분수·소수·약수와 배수·혼합 계산), 서우는 구구단(더하기·빼기로 전환 가능). 정답마다 ⭐.
  - 주말 TV 30분 타이머(시작·일시정지·초기화, 종료 알림음)
  - 오늘의 속담·오늘의 영단어(그림 카드 + 음성 듣기, Web Speech API)
- **시간표**: 오늘/주간을 오가며 아이별 시간표를 봅니다. `일정 편집`으로 추가·수정·삭제.
- **급식**: 함박초등학교 점심 급식표를 이번 주·다음 주(월~금)로 넘겨 봅니다. 알레르기 번호 토글.
- **숙제**: 아이별 체크리스트.
- **편집**: 공부 목록을 아이·요일별로 추가·수정·삭제·기본값 복원. 홈 카드의 `✏️ 목록 수정`을 눌러도 같은 편집기가 열립니다. 시간표 백업(JSON)·불러오기·초기화도 여기서 합니다.

공부 목록 기본값은 서연(매일): 학교숙제·영어숙제·수학숙제·한글책 읽기·리딩게이트,
서우(요일별): 월 퍼플 Into Reading/디딤돌/소마셈 나눗셈/리딩/한글책/국어 2장, 화 퍼플 Know It Show It/라이팅/디딤돌/소마셈 덧셈뺄셈, 수·금은 퍼플 Language Fundamentals·Main Writing, 목은 퍼플 IXL/Phonics Activity/1031 등입니다.

고친 내용은 그 기기의 브라우저 저장소(localStorage)에 저장되며 서버로 전송되지 않습니다.
`편집 → 백업 파일 저장`으로 JSON 파일로 백업하거나 되돌릴 수 있습니다.

## 파일

- `index.html` — 화면과 동작 전체
- `meals.json` — 함박초 급식표(이번 달 + 다음 달, 중식). 없거나 비어 있으면 화면이 NEIS에서 직접 받아 옵니다.
- `manifest.json`, `sw.js`, `icon*.png`, `apple-touch-icon.png` — 홈 화면 추가 및 오프라인용 (`sw.js`의 `CACHE` 버전을 올리면 설치된 기기도 새 화면을 받습니다)
- `tools/make-icons.py` — 아이콘 생성 스크립트
- `tools/fetch-meals.py` — NEIS에서 급식표를 받아 `meals.json`을 새로 만드는 스크립트 (5일 단위 요청, API 키 불필요)

## 자료 출처

- 급식: 교육부 NEIS 식단 정보 API(`open.neis.go.kr`, 경기도교육청 `J10` / 함박초등학교 `7751355`)
- 날씨·미세먼지: Open-Meteo (forecast / air-quality), 용인 좌표 37.2411, 127.1776 — 실패하면 화면에 안내 문구를 보여 줍니다.
